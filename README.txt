SÜHA AKYEL — PORTFÖY SİTESİ

DOSYALAR
- index.html          Ana sayfa
- akademik.html       Eğitim ve akademik odak
- yeteneklerim.html   Teknik beceriler
- yarismalar.html     Projeler
- gezilerim.html      Gezilerim
- iletisim.html       İletişim bağlantıları
- style.css           Tüm sayfaların tasarımı
- script.js           Mobil menü, ikonlar ve animasyonlar

YERELDE AÇMA
1. ZIP dosyasını bir klasöre çıkar.
2. index.html dosyasını tarayıcıda aç.
3. Geliştirme için VS Code ve Live Server kullanabilirsin.

YAYINA ALMA
GitHub Pages, Netlify veya Cloudflare Pages gibi statik site barındırma hizmetlerine
bu klasördeki dosyaları yükleyebilirsin. Tüm sayfa dosyaları aynı klasörde kalmalı.

GEZİLERİM SAYFASI
gezilerim.html sayfasındaki fotoğraflar için images/ klasörü oluşturup şu dosyaları ekle:
- images/teknofest-2025.jpg
- images/canakkale.jpg
- images/istanbul.jpg
Fotoğraf yoksa sayfa yine çalışır; kartlarda koyu gradient arka plan görünür.

YAYIN ÖNCESİ KONTROL
- LinkedIn ve GitHub bağlantılarının doğru açıldığını kontrol et.
- Proje durumlarını ve beceri listesini güncel tut.
- Gerçek olmayan ödül, derece, iş deneyimi veya uzmanlık iddiaları ekleme.
- Google Fonts ve Lucide ikonları internet bağlantısıyla yüklenir.

Not: İletişim formu yerine LinkedIn ve GitHub bağlantıları kullanılır.
